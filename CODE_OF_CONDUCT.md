# Code of Conduct

## The standard

Be respectful and assume good faith. Disagree about the work, not the person.
Technical criticism is welcome and expected; personal attacks, harassment,
discriminatory language and sustained disruption are not.

## Scope

This applies in issues, pull requests, commit messages and any other project
space, and to anyone taking part.

## Reporting

Report a problem privately through GitHub private vulnerability reporting,
which is enabled on this repository and reaches the maintainers without being
public:

<https://github.com/ansh-n-chovatiya/context-ledger/security/advisories/new>

That channel is for conduct as well as vulnerabilities; there is deliberately
no email address here, because an address in a public file is a spam target and
one nobody monitors is worse than none.

## Enforcement

The maintainers will review what is reported and respond as they judge
appropriate, from a warning to a permanent ban from project spaces. Reports are
handled discreetly, and the reporter's identity is not shared with the person
reported without consent.

## Attribution

Adapted in spirit from the Contributor Covenant, kept short deliberately: a
policy nobody reads protects nobody.
